---
title: "Improve with AI"
description: "One-click AI improvement for descriptions and impact statements"
---

The **Improve with AI** button appears on every description and impact field in the dashboard.

## Usage

1. Click **Improve with AI** next to any text field
2. AI rewrites the text to be more specific, quantified, and impact-focused
3. Review the suggestion in a side-by-side modal
4. **Accept** — replaces the field with the suggestion
5. **Try again** — fires another AI call for a different suggestion
6. **Dismiss** — keeps the original

## AI Provider

The AI provider is configured in **Settings**. Requests always read settings from the database — never cached — so you can change providers without restarting.
