## Endpoints

### GET /api/v1/profiles/me

Returns the current user's profile.

**Response** `200 OK`
```json
{
  "id": "uuid",
  "user_id": "dev-user",
  "name": "Dev Sarangi",
  "headline": "Principal Consultant",
  "summary": "...",
  "location": "Sydney, AU",
  "avatar_url": null,
  "cover_url": null,
  "email": "dev@example.com",
  "website": null,
  "linkedin_url": null,
  "created_at": "2026-06-27T00:00:00",
  "updated_at": "2026-06-27T00:00:00"
}
```

**Error** `404` — profile not yet created

### POST /api/v1/profiles/me

Create a new profile.

**Body**
```json
{
  "name": "Dev Sarangi",
  "headline": "Principal Consultant",
  "summary": "...",
  "location": "Sydney, AU",
  "email": "dev@example.com"
}
```

### PATCH /api/v1/profiles/me

Update profile fields. All fields optional.
